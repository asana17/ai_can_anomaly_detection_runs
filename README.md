# ai_can_anomaly_detection_runs

Runs of the detector comparison in
[asana17/ai_can_anomaly_detection](https://github.com/asana17/ai_can_anomaly_detection).
Each `results/<start time>/` is one run of `evaluate.pc.run`, added by the run itself.

What the files in a run hold is described in
[evaluate/docs/run_record.md](https://github.com/asana17/ai_can_anomaly_detection/blob/main/evaluate/docs/run_record.md).
The format can change between commits, so read that page at the `commit` in the run's
`meta.json`.
